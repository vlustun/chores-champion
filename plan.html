Summary: `composer install` fails inside the Xdebug `app` container because that container runs as `www-data` (uid 33). `compose.xdebug.yaml` bind-mounts `.:/app`, and the host-owned `vendor/` (uid 1000) is not writable by that user. Composer's home, `/var/www/.composer`, is not writable either. The plan is to stop installing as `www-data` and give the dev container a writable, uid-matched setup.
Stack: Docker Compose (php:8.3-fpm `fpm-dev` target, `cli` tools image), Composer 2, Make, Symfony. Run with `docker compose -f docker-compose.yml -f compose.xdebug.yaml up -d --build app`.
